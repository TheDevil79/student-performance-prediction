## Project Overview

This project uses the [UCI/Kaggle Student Performance Dataset](https://www.kaggle.com/datasets/uciml/student-performance-data-set) (`student-mat.csv`) to train a regression model that predicts final math grade **G3** (0–20) without using interim grades G1 or G2, preserving academic integrity of the prediction.

**Tech stack:** Python 3.11 · FastAPI · scikit-learn · pandas · joblib · Uvicorn · Vanilla JS frontend

---

## Model Metrics

Trained on 395 student records (80/20 split, `random_state=42`):

| Split           | MAE    | RMSE   | R²     |
|-----------------|--------|--------|--------|
| **Test set**    | 3.0828 | 3.8638 | 0.2719 |
| Train set       | 1.3694 | 1.8747 | 0.8327 |
| 5-Fold CV (MAE) | 3.1884 | —      | —      |

> **Interpretation:** The test MAE of ~3.1 points means on average the model is off by about 3 grade points on the 0–20 scale. The relatively low test R² (0.27) reflects the difficulty of predicting grades purely from socio-demographic factors (without G1/G2). Predictions are **statistical estimates**, not guaranteed grades.

```
data/student-mat.csv
```

The file uses **semicolons** (`;`) as delimiters — `train.py` handles this automatically.

## Training the Model

Run from the project root:

```bash
python train.py
```

What it does:
- Loads and validates `data/student-mat.csv`
- Builds a scikit-learn pipeline: `ColumnTransformer` (StandardScaler + OneHotEncoder) → `RandomForestRegressor`
- Performs 80/20 train/test split and 5-fold cross-validation
- Saves the fitted pipeline to **`model.joblib`**
- Writes metrics to **`evaluation_report.json`**

`model.joblib` is the **single shared artefact** used by both `train.py` and the FastAPI app — they are always in sync.

## API Reference

### GET /health

```json
{
  "status": "healthy",
  "model_loaded": true,
  "model_path": "model.joblib",
  "version": "1.0.0",
  "message": "Model ready for inference"
}
```

Returns `"status": "degraded"` if `model.joblib` is missing (run `python train.py` first).

### POST /predict

Send 30 student attributes, receive a predicted G3 grade.

**Request body (JSON):**

```json
{
  "school": "GP", "sex": "F", "age": 17,
  "address": "U", "famsize": "GT3", "Pstatus": "T",
  "Medu": 4, "Fedu": 4, "Mjob": "health", "Fjob": "teacher",
  "reason": "reputation", "guardian": "mother",
  "traveltime": 1, "studytime": 3, "failures": 0,
  "schoolsup": "no", "famsup": "yes", "paid": "yes",
  "activities": "yes", "nursery": "yes", "higher": "yes",
  "internet": "yes", "romantic": "no",
  "famrel": 5, "freetime": 3, "goout": 2,
  "Dalc": 1, "Walc": 1, "health": 5, "absences": 2
}
```

**Response:**

```json
{
  "predicted_grade": 14.16,
  "rounded_grade": 14,
  "performance_level": "Good (14-15)",
  "scale_min": 0.0,
  "scale_max": 20.0,
  "status": "success"
}
```

Predictions are clamped to `[0.0, 20.0]`. They are **statistical estimates — not guaranteed grades**.

## Frontend

Served automatically at `/` by FastAPI when the `static/` directory exists.

- Calls `GET /health` on page load to show live API status.
- Sends `POST /predict` on form submission via `fetch()`.
- Renders grade gauge, performance tier pill, and interpretation text.
- Shows a prominent disclaimer that the output is an estimate, not a guaranteed grade.

## Deployment Notes

> No paid deployment has been performed or verified. These instructions describe the process.

### Render (free tier)

1. Push the repo to GitHub (include `model.joblib` — it is ~1.7 MB).
2. Create a **Web Service** on https://render.com.
3. **Build Command:** `pip install -r requirements.txt`
4. **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. Render injects `PORT` automatically.

### Docker-based (AWS ECS / GCP Cloud Run / Azure App Service)

```bash
docker build -t student-perf-predictor .
docker tag student-perf-predictor <registry>/student-perf-predictor:latest
docker push <registry>/student-perf-predictor:latest
```

Then create a service using your cloud provider's container platform.

## Important Caveats

- **G1 and G2 are intentionally excluded** from training and the API schema. The model predicts from demographic and social factors only.
- **Predictions are statistical estimates.** Test MAE ~3.1/20; individual predictions can deviate further. Do not use as a substitute for actual academic assessment.
- **Small dataset (395 students)** from two Portuguese secondary schools. Generalisation to other populations is not guaranteed.
